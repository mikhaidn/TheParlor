PROPOSAL · REPLAY CODE V1

One byte per move

A solve becomes a short code: who dealt what, then every action the player took, undos included. Paste it or scan it and the replay rebuilds the game step by step. The example on this page is a real solve of Daily #2 (deal #8927), encoded by the shipped encoder and decoded back to a won game.

Foundations get four positions (one per suit) even though the target is implied by the card’s suit. That keeps the map a clean 16, and because a foundation is never a move’s source, every byte that starts with 4–7 is free for control tokens.

When is depth needed?
The rules already fix how many cards move in every case but one:
To a cell or a foundationalways 1 card From a cellalways 1 card Onto a card in a columnonly one run length fits Column to an empty columnadd one nibble
57 · 7♥ and 1 more to empty column 7 → C E 1
In the sample solve, 8 of 84 actions needed it. Moves are a stream of 4-bit nibbles, so depth costs half a byte, and a lone trailing 4 pads an odd stream.

Auto-moves aren’t stored
The header says which auto-move setting was on (off, safe, always). The replayer runs the same engine after each move, so the 33 cards that went home by themselves in this solve cost nothing. The version byte pins the auto-move rules, so an old code still plays back if those rules change later.

6 · What counts as a move

Every card move on the board when you win counts, including cards that went home by themselves. Undo, hints and restarting are free: an undo takes its move off the count, and a restart clears the count, but the clock keeps running.
That’s what the app counts today, so Best-moves stats stay valid. The code still records every undo and restart, so the replay can show the solve as played (84 steps), wrong turns and all.
Casual dailies work this way: NYT puzzles have no move penalty, and only help like Check or Reveal costs the streak. Score-chasing solitaire sites charge a move per undo instead.

7 · Locked in, and shared without spoilers

Locked in at the winThe first solve is the record: time, moves and this code are saved the moment the last card goes home. Playing the deal again is practice and never changes it.
